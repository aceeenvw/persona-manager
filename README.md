# ⊹ PERSONA MANAGER ⊹

A mobile-friendly Persona Manager for SillyTavern. Browse, organize, and edit your
personas in one themed window.

## Features

- Portrait cards with favorites, status badges, and quick editing.
- Optional avatar cropping with freeform and preset ratios.
- Search, filters, sorting, folders, and bulk actions.
- Full-screen editor with autosave, lorebooks, connections, and private notes.
- Create personas or convert existing characters.
- ZIP backup, restore, and selected-persona export.
- Adjustable card sizes, image ratios, pagination, and six themes.
- Touch-friendly controls and English / Russian UI.

## Installation

Paste `https://github.com/aceeenvw/persona-manager` into SillyTavern's extension
installer, then reload.

## Usage

Open **Persona Management**. Click a card to use that persona or its pencil to edit.
In the editor, click the avatar to change its image or the name to rename it.
The folder button opens the sidebar; `⋯` contains Convert, Theme, and Backup / Restore.

Extension settings let you disable upload cropping or restore the native persona panel.
