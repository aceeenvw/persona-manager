# ⊹ PERSONA MANAGER ⊹

A prettier, mobile-first replacement for SillyTavern's native Persona Management panel.

> Work in progress.

## Features (planned)

- Hijacks the native Persona Management drawer with a clean, themed modal.
- Folders, tags and favorites to organize large persona libraries.
- Active-persona spotlight with live lock toggles (chat / character / default).
- Full editor: description, position, depth, role, connections, lorebook binding.
- Token-budget bar and a guided "Help mode" for authoring personas.
- Bottom-sheet editor and full-screen takeover tuned for mobile.
